# Style guide — Status: DRAFT

Written by the director stage after 3 competing directions; the chosen one only.
- **Device:** the one visual idea the film is built on (sayable in a sentence).
- **Signature move:** the one moment people will remember; spent once.
- **Registers:** background A = the argument, background B = the product; each switch is a turn in the story.
- **Palette / type:** one display face, one UI face, one accent.
- **Motion:** personality, springV durations (entry / exit = 65–75 % of entry), CURRENT, seams used (2–3 kinds).
- **Sound:** music bed, where the silence before the payoff goes, the loudest hit.
