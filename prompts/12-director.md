# Stage 2 — Director (+ jury)
Input: APPROVED script. Output: docs/style_guide.md for the chosen direction only.

```
Propose 3 directions for the APPROVED script that really differ, each with: the device (one visual idea, sayable in
one sentence), the signature move (one moment, spent once), two registers (argument vs product backgrounds),
personality, palette and type, the 2–3 seam kinds, and the frame-0 cover. Describe one key frame per direction
precisely enough to draw it.
```
Then a separate, fresh agent is the jury: it reads only docs/brief.md and the 3 directions, scores each 1–10 on
"does the picture prove the claim", "readable on a phone", "memorable", "fits the personality", and says which
two to kill. The user picks; the director writes docs/style_guide.md (DRAFT → user approves).
